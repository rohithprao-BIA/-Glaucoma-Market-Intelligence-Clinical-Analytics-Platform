# Source Data

This folder contains the seven relational database tables used in the Glaucoma Market Intelligence & Clinical Analytics Platform.

The tables contain commercial, pricing, molecule, clinical evidence, guideline, and safety information used for SQL analysis and Power BI visualization.

## Tables

- Companies.xlsx
- Products.xlsx
- Pricing.xlsx
- Molecules.xlsx
- Clinical_Evidence.xlsx
- Guidelines.xlsx
- Safety_Profile.xlsx
